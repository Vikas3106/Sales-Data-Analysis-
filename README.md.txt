# Sales Data Analysis

## 1. Project Overview
This project analyzes sales data to identify important sales and profit patterns using Python and Power BI.

## 2. Problem Statement
The objective is to analyze sales performance across products, regions and categories and generate useful business insights.

## 3. Dataset Description
The dataset contains sales transaction records with the following fields:
- Date
- Product
- Region
- Quantity
- Category
- Unit Price
- Sales
- Profit

## 4. Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Power BI
- Git & GitHub

## 5. Data Cleaning & Preparation
The dataset was checked for:
- Missing values
- Duplicate records
- Incorrect data types
- Invalid values

Missing values were handled and duplicate records were removed before analysis.

## 6. Exploratory Data Analysis
EDA was performed to analyze:
- Product-wise sales
- Region-wise sales
- Category-wise sales
- Product-wise profit
- Monthly sales trends
- Correlation between numerical variables
- Outliers

## 7. Visualizations
The project contains meaningful visualizations such as:
- Product-wise Sales Chart
- Region-wise Sales Chart
- Category-wise Sales Chart
- Product-wise Profit Chart
- Monthly Sales Trend
- Correlation Analysis
- Outlier Analysis

## 8. Power BI Dashboard
An interactive Power BI dashboard was created with:
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Product-wise Sales
- Region-wise Sales
- Category-wise Sales
- Monthly Sales Trend
- Product, Region and Category filters

## 9. Key Insights
1. Electronics is the highest-performing category in terms of sales.
2. South Region has the highest total sales.
3. Laptop is the top-selling product and generates the highest profit.
4. Monthly sales show significant variations.
5. Total sales are approximately 69M and total profit is approximately 11.60M.

## 10. Recommendations
1. Focus more on high-performing products such as Laptops and Electronics through inventory planning and promotions.
2. Improve lower-performing regions and categories using targeted offers and marketing campaigns.

## 11. Conclusion
The analysis provides a clear overview of sales and profit performance. Python-based EDA and Power BI visualization help identify important trends and support data-driven business decisions.
